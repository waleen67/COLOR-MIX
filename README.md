# Color Mixer

A simple Python program that simulates color mixing. Enter two colors to see what color they create when mixed together.

## Features

- Mixes primary colors (red, blue, yellow)
- Mixes secondary colors (green, orange, purple)
- Mixes colors with black to create darker shades
- Mixes colors with white to create lighter shades
- Mixes two identical colors (returns the same color)

### Supported Colors

**Base colors:**
- red
- blue
- yellow
- green
- orange
- purple
- black
- white

### Mixing Results

| Mix | Result |
|-----|--------|
| red + blue | PURPLE |
| red + yellow | ORANGE |
| blue + yellow | GREEN |
| red + purple | RED-PURPLE (Magenta) |
| blue + purple | BLUE-PURPLE (Violet) |
| red + orange | RED-ORANGE |
| yellow + orange | YELLOW-ORANGE |
| blue + green | BLUE-GREEN (Cyan) |
| yellow + green | YELLOW-GREEN |
| black + red | DARK RED |
| black + blue | DARK BLUE |
| black + yellow | DARK YELLOW (Olive) |
| black + green | DARK GREEN |
| black + purple | DARK PURPLE |
| black + orange | DARK ORANGE (Brown) |
| white + red | PINK |
| white + blue | LIGHT BLUE |
| white + yellow | LIGHT YELLOW |
| white + green | LIGHT GREEN |
| white + purple | LAVENDER |
| white + orange | PEACH |
